## High-risk dependency edges to preserve

- `runtime/zig/sdk/root.zig` and vendored SDK compatibility roots are consumed by both build graph wiring and generated outputs.
- `tests/Cargo.toml` plus root `*_test.rs` files are the stable Rust entrypoint; moving them without same-change manifest edits would break the Mollusk suite.
- `examples/tests/*.ml` is a behavioral contract for `omlz test` default discovery, not just a directory preference.
- `out/program.zig`, `out/native_entry.zig`, `out/bpf_entry.zig`, and `out/runtime/**` are default artifact locations that CLI help text, docs, and tests already assert.
- Root automation files (`build.zig`, `init.sh`, `Makefile`, `package.json`, `.github/workflows/ci.yml`) are compatibility surfaces, not merely implementation details.
